# Database & ERP Coursework

A curated university sample project covering relational database work and ERP/material-consumption analysis.

## Repository map

```text
sql-database/  schema, synthetic seed data, transaction scenarios and results
erp-analysis/  synthetic material movements and calculated results
```

## Skills demonstrated

- Relational schema interpretation
- SQL data definition and queries
- Translating business cases into data operations
- Reasoning about articles, transactions and material consumption
- Connecting database work with ERP process concepts

## Important naming note

The original course folders use the abbreviation `AWS`. In this context it refers to the university course, **not Amazon Web Services**. This repository deliberately avoids presenting the work as AWS cloud experience.

## Repository scope

The repository contains selected implementation results—not assignment sheets, instructor material, local databases or a general answer key. Files were renamed from their original course-delivery names so the collection reads as a self-contained technical sample.

## Data privacy

**All names, addresses, customer records, product records, transaction values and material-movement values in this repository are synthetic university exercise data.** They do not describe real people, customers or businesses.

The SQL demonstrates schema interpretation, inserts and transaction handling. The ERP files preserve computed results and inventory movements for reproducibility.
